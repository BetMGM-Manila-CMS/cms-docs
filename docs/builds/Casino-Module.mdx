# Casino Module

## Creating Casino Module

First, navigate to the directory of the Casino Module:

<Admonition type="info" title="Sitecore Path">
  Content > Vanilla.Mobile > State/Brand > MobileCasino-v1.0 > LMTCategories > instantCasino > Category\_ID
</Admonition>

The Category\_ID will differ for every ticket, so make sure to check the Workfront ticket for the details.

![](https://res.cloudinary.com/dlfu36fiw/image/upload/v1786424710/builds/casino-module/cabinetmodule_5_m5t4oy.png)

In the example above, the Category ID is triplestones\_home.

![](https://res.cloudinary.com/dlfu36fiw/image/upload/v1786424713/builds/casino-module/cabinetmodule_6_jilstq.png)

### Title

Edit the Title and cabinettitle to match what was given in Workfront, or copy it if provided.![](https://res.cloudinary.com/dlfu36fiw/image/upload/v1786424716/builds/casino-module/cabinetmodule_1_utbyxa.png)![](https://res.cloudinary.com/dlfu36fiw/image/upload/v1786424719/builds/casino-module/cabinetmodule_2_uvonmh.png)

### Images

Add the "749x503" asset to the FullTakeOverStaticBackgroundImage.![](https://res.cloudinary.com/dlfu36fiw/image/upload/v1786424723/builds/casino-module/cabinetmodule_3_wfzs8v.png)

For the CabinetModuleLogo you can insert the Logo asset provided. 

CabinetModuleDescription > Description provided in the Workfront.![](https://res.cloudinary.com/dlfu36fiw/image/upload/v1786424726/builds/casino-module/cabinetmodule_4_aavhfm.png)

### Publishing

Make sure to Tick to Never Publish.
